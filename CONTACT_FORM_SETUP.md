# Boost Mind Contact & Project Inquiry

Public contact email:

```text
info@boostmind-tech.com
```

It is shown in the Contact section, Start Project modal, and footer.

Project inquiry notifications are delivered to:

```text
bishosamuel@gmail.com
```

Reply-To is the email submitted by the client.

The live endpoint is:

```text
POST /api/project-inquiry
```

Run the automated worker checks with:

```bash
npm run test:inquiry
```

For Cloudflare configuration, see `CLOUDFLARE_EMAIL_SETUP.md`.
