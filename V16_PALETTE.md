# Boost Mind v16 — Premium Palette

The C4D motion system and page structure are preserved from v15. This release changes the visual identity only.

## Approved palette
- Porcelain — `#F4F2ED` — primary page background
- Cloud — `#EEF3F4` — secondary surfaces
- Midnight — `#0B2236` — headings / dark surfaces
- Atlantic — `#176A96` — primary brand/action color
- Muted Teal — `#6FA7A2` — restrained accent used to break the blue without orange or violet
- Brushed Steel — `#AEBBC3` — borders / metallic neutral
- White — `#FFFFFF` — cards / clean contrast

## Intent
Premium software + engineering: calm, precise, credible and modern. No neon cyan, orange, purple, or multi-color SaaS gradients.
