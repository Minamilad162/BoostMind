# Boost Mind v25 — Simple Start Project Form

The Start Project form now contains only:
- Full name (required)
- Email (required)
- Phone / WhatsApp (required)
- What do you want to build? (required)
- Reference link (optional)

Removed from both frontend and backend validation/email:
- Company / organization
- Project type
- Budget
- Timeline
- Preferred contact
- Consent checkbox

The anti-spam honeypot, timing validation, Cloudflare email notification, Reply-To behavior, health endpoint, and optional inquiry storage remain intact.
